## 📊 Animation Layers

```
Layer 1: Background Motion
  └─ Animated gradient circles (Framer Motion)

Layer 2: Component Entry
  └─ Hero title (opacity + y-axis)
  └─ Stat cards (staggered delay)

Layer 3: Interactive Elements
  └─ Dropdown (scale on hover)
  └─ Update button (scale on appear + hover)
  └─ Table rows (staggered fade-in)

Layer 4: Feedback
  └─ Toast notification (slide-in + scale)
  └─ Row hover (background color change)

Layer 5: Exit
  └─ Toast exit animation (reverse order)
```
